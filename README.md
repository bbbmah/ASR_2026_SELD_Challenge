# ASR 2026 SELD 챌린지 작업 기록

STARSS23(실제 방에서 녹음한 소리와 360° 영상)으로 **카메라가 움직이는 시청각 소리 방향 추정(AV-SELD) 챌린지 데이터셋**을 만들고, 베이스라인으로 실험한 작업의 기록입니다. 이 저장소는 **작업 흐름을 되짚고 과거 코드를 찾기 위한 것**이라서 코드, 설정, 노트북, 문서, 작은 결과표만 있습니다.

## 저장소에 없는 것 (일부러 뺌)

| 없는 것 | 이유 |
|---|---|
| 데이터셋(영상, 오디오, 라벨, zip), 특징, 체크포인트 | 용량이 크고(수십~수백 GB) 드라이브에 있음 |
| test 정답과 test 카메라 자세, 매니페스트 | 챌린지 평가용 비공개 정보 |
| **무작위 시드 값** | 공개 코드와 합쳐지면 비공개 test 구성을 재현할 수 있어서, 코드와 문서의 시드 값은 이 저장소에서 `0` 또는 `<비공개>`로 바뀌어 있습니다. 그래서 이 코드를 그대로 돌려도 같은 데이터는 나오지 않습니다 |
| 남의 저장소 코드 두 개(DCASE2025 베이스라인 원본, Sony 데이터 생성기) | `UPSTREAM.md` 참고 |

## 문서 지도

| 문서 | 내용 |
|---|---|
| `CLAUDE.md`, `rev_Ctrl5.md`, `MODEL_CODE_CH.md` | 작업 지침서(데이터셋 만들기, ctrl5 다시 만들기, 베이스라인 고치기) |
| `dataset/INTRO_dataset.md` | 챌린지와 데이터셋을 처음 보는 사람을 위한 소개 |
| `dataset/README_dataset.md`, `dataset/BUILD_REPORT.md`, `dataset/NOTES.md` | 데이터셋 형식, 생성 결과 보고, 정한 것과 기본값 |
| `CHANGES.md`, `CHECK_REPORT.md` | 원본 베이스라인 대비 변경 내용과 확인 결과 |
| `README_baseline.md` | 코랩 학습 사용 설명서 |
| `RESULTS_REPORT.md` | main20, ctrl5 x B1, B2, B2-0, B3 학습 결과 보고 |
| `DATA_PLAN_v2.md`, `README_generate.md` | 추가 학습 데이터 확장 플랜과 생성 노트북 사용법 |
| `LOCAL_CLEANUP_PLAN.md` | 로컬 저장소 정리 계획과 결과 |

## 폴더

| 폴더 | 내용 |
|---|---|
| `build/` | 데이터셋 생성, 검증, 평가, 분석 스크립트와 노트북 생성 스크립트 |
| `baseline/seld_challenge/` | 고친 베이스라인 학습 코드, 설정(`configs/`), 학습 노트북(`colab_run.ipynb`) |
| `colab_generate.ipynb` | 추가 학습 데이터 생성 노트북 |
| `seld_runs/` | 실험 결과표와 실행별 작은 기록(학습 로그, 점수, 설정) |

## 변경 이력 규칙

파일을 고칠 때마다 그 파일 맨 위의 `변경 이력` 주석에 날짜와 내용을 한 줄 추가합니다(`build/add_history.py`의 `HIST`에서 관리). 이 저장소의 커밋은 요청이 있을 때만 하며, 올릴 파일은 `build/publish_sync.py`가 고릅니다(시드 값 가리기, 노트북 실행 결과 지우기 포함).
